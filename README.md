# Tesla_Stock_Plot
- 📈 Tesla Stock & Revenue Visualization
- 💸 This project visualizes Tesla's stock price and revenue data using Plotly. 
- 💹 It includes a function to generate interactive graphs with subplots for share price and revenue trends, filtered up to June 2021.
- Data is cleaned and formatted to handle currency symbols and missing values.
